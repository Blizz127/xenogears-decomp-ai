# Opening Fei replacement atlas

fan-made, AI-generated replacement sprite art created for this project; not from the game; characters © Square Enix

`fei-octopath-v2.png` is new original artwork generated using the built-in image generation tool. The existing project-made Fei atlas was a costume/identity reference, not a source of retail pixels. The sixteen authored poses cover front, back, left and right views. Two left-facing poses were corrected with the image tool. No resampling or pixel filtering was applied after generation. Existing `assets/fei_hd2d` and its enablement behavior remain untouched.

`fei-octopath-v2.authored.json` records alpha-inspected, nonuniform sprite rectangles. The generated image does not fit a perfectly equal grid: inspect complete silhouettes rather than clipping feet to guessed cell boundaries. This is an authoring manifest, **not runtime animation metadata**. Its game mappings and approved maps are deliberately empty pending verified frame-index traces, anchors and coordinator agreement. Do not present this artwork review as an in-game animation acceptance. Prompts and provenance are in `../ART_PROMPTS.md`.

Author an RGBA PNG at native pixel resolution and `atlas.json`. Schema 1 has `label` exactly as above, integer `width`/`height` (1–4096), explicit `maps` (1–32 unique opening-map IDs), and `frames` (1–256 records). Each frame has exactly `animation`, `cursor`, `facing`, `x`, `y`, `width`, `height`, `foot_x`, `foot_y`. Coordinates are pixels; foot anchors are relative to the rectangle and may lie on its bottom edge. Facing is a renderer-supplied index 0–15. Confirm map IDs and facing convention before authoring mappings.

Every `(animation, cursor, facing)` key is exact. The caller reads the game-owned cursor; the atlas does not divide it, synthesize timing, wrap it, or map unknown poses. Missing keys retain original primitives. Idle, walk and run require separate explicitly verified cursor mappings. Existing Fei code reads camera-relative angle at sprite offset `0x80` and cursor at `0x34`; those observations do not prove all cursor values or poses.

Run `python3 pc_port/tools/compile_hd2d_atlas.py atlas.json original.png output_directory`. Pillow is an authoring-only dependency for PNG; `.rgba` input requires standard Python only. The converter rejects malformed/out-of-bounds metadata, duplicate mappings, mismatched image sizes, and fully transparent mapped frames before writing `atlas.rgba`, `atlas_metadata.c`, and normalized JSON. Preserve the original PNG separately.

The independent C loader checks metadata and exact RGBA byte length before publishing a buffer. Upload only after success, with nearest minification/magnification and no mipmaps. Use pixel rectangles directly where the renderer supports them; avoid the baseline's 8-bit UV quantization. Caller must retain original primitives until replacement readiness is established, reject more than 64 parts, and restore captured originals if rendering fails. Texture lifetime belongs to the renderer. Master Off must bypass this module and maintain the current rendering path exactly. No shared integration hooks or configuration are installed by this module.

Validation: `pc_port/tests/run_hd2d_sprite_atlas_test.sh` runs independent O0/O2/UBSan tests. Art approval also requires village/interior previews at native and enlarged scale, correct anchors, silhouettes, directions, animation cadence, alpha edges, foreground occlusion, and nearest sampling. Production map allowlist and animation mappings remain pending verified opening scene observations.
