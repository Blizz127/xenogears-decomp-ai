Available now
  Grade, vignette, warm ambient and projected radial lights can operate on the
  existing color presentation. They do not resample or soften sprite edges.
  Every effect has an independent enable/intensity in [0,1] (invalid values
  disable; finite values over 1 clamp). No output work if all effects bypass.
  Lighting is a stylized projected falloff accent, not world-space lighting.

Required inputs for remaining effects
  Bloom and ground-contact shadows require a verified, current R8 protection
  mask for ALL visible sprites AND in-game UI. The mask is 1 on protected pixels,
  0 on environment pixels. Rendering keeps protected RGBA pixels exactly intact,
  and blur/glow taps exclude them. Fei's bounding box alone is not sufficient:
  it overprotects scenery and leaves NPCs/text unprotected. Shadow ellipses are
  supplied from actual projected feet/ground contacts, not inferred screen Y.

  DOF (including tilted focal plane), fog and particles ALSO require an R32F
  texture with positive linear view-distance values, 0 for invalid/unknown.
  Format, dimensions and explicit semantic validity are checked. Missing or
  malformed depth disables these effects. There is no screen-Y depth fallback.
  The shader uses tilt only to tilt the focal plane in true depth units.
  Particles are explicitly supplied projected scene particles with real depth;
  they are culled against scene depth and never overlay protected pixels.

Minimal renderer work to unlock depth/mask (separate scoped integration)
  Current inspected PsyCross blit/offscreen FBOs attach depth texture 0. Its
  optional PGXP depth test alone does not prove usable camera-depth data for
  this non-PGXP port. A new depth attachment filled with default z is insufficient.
  Introduce current-frame, viewport-sized R8 coverage and R32F distance targets,
  allocated ONLY while master is ON and the approved field is active.
  Emit matching auxiliary draws in retail raster/order-table order: sprite/UI
  alpha-surviving pixels write coverage=1, environment pixels overwrite coverage
  to 0 where they obscure sprites. Use the same clipping and discard semantics.
  Preserve sprite/UI fragments behind later environment geometry correctly.
  Derive linear depth from verified GTE camera-space per-vertex metadata carried
  to renderer vertices, not ordering-table bucket index or window-space y.
  Define transparency policy before marking coverage/depth complete. Unknown
  world/background or partially covered fragments must use depth=0; unknown
  coverage means do not mark protection_verified for that frame.
  Cached VRAM image presents cannot inherit live scene attachments. Store matching
  auxiliary data with that specific image or explicitly invalidate it.
  Emit explicit status showing effect unavailable until this producer is wired.
